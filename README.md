# 🔁 Autonomous Contribution Reward System

### 🌐 Empowering Open Source Contributors with Transparent, Autonomous Rewards

---

## 🚀 About the Project

In the open-source ecosystem, many impactful contributors go **unrewarded**, To solve this, we built an **Autonomous Contribution Reward Agent** — a decentralized system that:

- Detects **meaningful contributions** (PRs, issues) from GitHub.
- Rewards contributors with **SPL tokens** on the **Solana blockchain**.
- Operates with **no manual intervention** in the reward process.
- Uses human review only for PR verification and merging.

> This project is built using **Coinbase Developer Platform (CDP)**, **Phantom Wallet**, and integrates **GitHub** with blockchain to enable real-time decentralized incentives.

---

## 🧠 Key Features

- 🔗 **GitHub to Blockchain** integration
- 🤖 **Autonomous contribution agent** (no human approval for rewards)
- 🏆 **Token-based incentives** for PRs and issues
- 🔐 **Authentication via Clerk + MetaMask**
- 🛠️ **Real-time GitHub project management dashboard**
- 🧾 **Automatic GitHub App installation & repo linking**
- 💸 **Rewards in SOL/SPL tokens**
- 📬 **On-chain transaction history & tracking**

---

## 🛠️ Tech Stack

- **Frontend**: React, Clerk Auth, TailwindCSS
- **Backend**: Node.js, GitHub Webhooks, Express
- **Blockchain**: Solana, Phantom Wallet, SPL Token Integration
- **Database**: Supabase (optional for contributor metadata)
- **Authentication**: Clerk, OAuth
- **Tools**: GitHub Apps, GitHub API, Coinbase Developer Platform

---

## 🔁 How It Works

1. **Login & Auth**  
   - Sign in using Clerk or directly through MetaMask.
   - Your wallet is mapped with your GitHub identity.

2. **Connect GitHub Repositories**  
   - Authorize GitHub and link your open-source project.
   - The app installs a GitHub App to receive contribution events.

3. **Contribute Meaningfully**  
   - Create issues or raise pull requests.
   - PRs are reviewed and merged by maintainers.

4. **Automatic Reward Processing**  
   - Our autonomous agent analyzes the contribution impact:
     - Number of lines changed
     - Number of files affected
     - Type of contribution (PR, issue)
   - Rewards are automatically calculated and sent to your wallet.
   - Transactions are viewable in your Phantom Wallet and history panel.
